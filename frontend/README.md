# NetPulse Dashboard

Dashboard Next.js, React, Tailwind CSS dan Recharts.

```sh
npm ci
npm run dev
```

Buka http://localhost:3000 dengan backend pada port 8000.
Untuk API lain, isi NEXT_PUBLIC_API_URL di .env.local (termasuk /api/v1).
Produksi: `npm run build`, lalu `npm start`. Prototipe terpisah: `npm run demo`.
Login memakai password bootstrap backend. Registrasi menghasilkan viewer.
Lihat [konfigurasi keamanan](../SECURITY_SETUP.md).
